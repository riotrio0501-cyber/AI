# 投稿スケジュール（案）

## 1週間の形
| 曜日 | やること |
|---|---|
| 日 | まとめて3本作る（台本はできているので、生成→`build` するだけ） |
| 火 18:00 | ショート① 投稿 |
| 木 18:00 | ショート② 投稿 |
| 土 18:00 | ショート③ 投稿 |
| 月末の日曜 18:00 | 長尺のまとめ回（その月のショートをつないだ3〜5分） |

- 3つのアプリ（YouTubeショート・TikTok・Instagramリール）に**同じ時間**で出す
- 18時（日本時間）は日本の帰宅時間。ショートは数日かけて広がるので、時間はあまり気にしなくてよい
- 1か月たったら YouTube Studio の「視聴者がアクセスしている時間帯」を見て、時間を見直す

## 季節に合わせた順番
ネタの季節と実際の季節をそろえると、見る人が共感しやすい。

| 時期 | 出す回 |
|---|---|
| 12月〜2月（冬） | 02 かまくら → 03 最後のひと口 → 04 自撮り → 05 天気予報 → 新ネタ |
| 1月はじめ | お正月ネタ（もちつき など） |
| 2月はじめ | 節分ネタ（豆まき など） |
| **3月（春）** | **01 春なのに起きない**（雪解けの話なので、ここが一番合う） |

※ CLAUDE.md では「1本目＝春なのに起きない」だが、今は11月なので、**冬の回から出して、01は3月に出す**のがおすすめ。作る順番は01からでもかまわない。

## 1か月に必要なもの
| | 数 | クレジット |
|---|---|---|
| ショート | 約13本 | 1本 平均33 × 13 ＝ 約430 |
| 作り直しの予備（1割） | | 約45 |
| 長尺まとめ回 | 1本 | 0（作ったショートをつなぐだけ） |
| **合計** | | **約480 / 月** |

最初だけ、キャラの顔アップ（9）と全身の設定画が別にかかる。

## まとめ回（長尺）の作り方
- その月のショート8〜10本を、つなぎのカット（雪山の風景＋タイトル）をはさんでつなぐ
- 1話ごとに「第◯話 かまくら完成！」の小さなタイトルを入れる
- 縦型のままでなく、**横型 16:9 に作り直す**（左右を雪景色でうめる）。長尺は横型のほうがテレビやパソコンで見られやすい
- このための道具（`tools/compile.py`）は、ショートが数本たまった時点で作る
