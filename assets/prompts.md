# 絵の指示文（1本目「芋煮」）

ChatGPT でも Gemini でも使えます。上から順に、1つずつ貼り付けてください。

## コツ（大事）
1. **最初に「キャラ設定画」を作る** → その絵を毎回添付して「この人物で」と頼むと顔がブレにくい
2. **口開けは「編集」で作る** → 口閉じの絵を添付して「口だけ開けて、他は一切変えないで」
3. 気に入らなければ何回でも作り直してOK。顔が似ていない時は「設定画と同じ顔にして」
4. できた絵は **ファイル名（下の太字）を書き添えて** このチャットにアップロード

---

## 共通の画風（毎回、指示文の先頭にこの段落を付ける）

```
日本のテレビアニメ風のイラスト。セル塗り、くっきりした輪郭線、明るく自然な色。
表情は大げさでコミカル。オリジナルキャラクターで、既存のアニメ・漫画・実在の人物には似せない。
文字・ロゴ・吹き出しは入れない。
```
